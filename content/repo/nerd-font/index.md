# NerdFont

> 这里提供了**linux版本**的一键字体下载和配置脚本， 运行完之后只需要手动调整终端的字体就可以了

```bash
bash <(curl -fsSL https://repo.waterman.xin/fonts/install.sh)
```

> 如果下载失败可以选择下载这个并解压(跨平台适用)

```bash
wget https://repo.waterman.xin/fonts/nerd-font.zip
```
