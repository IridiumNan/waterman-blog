# zsh 主题插件

> 这里提供了zsh的相应主题插件打包一键配置的脚本， 不需要翻墙， 再次声明， 本仓库仅仅是打包配置而非原创， 版权属于原作者

- 如果你还没有安装 `zsh`

```bash
sudo apt install zsh -y # debian 系安装 zsh
```

- 然后使用脚本配置即可

```bash
bash <(curl -fsSL https://repo.waterman.xin/configs/zsh/config.sh)
```
